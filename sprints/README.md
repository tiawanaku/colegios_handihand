# Sprints exportados

Desde la página de agentes → **DESARROLLO** → "Exportar sprint para Claude Code", guarde el JSON aquí como `sprint-NN.json` y ejecute en Claude Code:

```
/sprint sprints/sprint-01.json
```

SCRUM_HANDIHAND reparte las tareas entre `dev1-handihand` (backend y datos) y `dev2-handihand` (frontend). Cada historia que pasa las pruebas queda en un commit, y al final recibe un bloque `avance-handihand` para pegar en la página ("Importar avance"). Ver `docs/07-desarrolladores.md`.
